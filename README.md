# 💕 Cita sorpresa

Invitación interactiva: ¿aceptas salir conmigo? → calendario y hora → lugar y punto de reunión → comida → final con corazones.

## Abrir en Visual Studio Code
1. Descomprime la carpeta `cita-sorpresa`.
2. En VS Code: **Archivo → Abrir carpeta…** y elige `cita-sorpresa`.
3. Instala la extensión **Live Server** (VS Code te la sugiere sola).
4. Clic derecho en `index.html` → **Open with Live Server**. Se abre en tu navegador.

## Configurar (al inicio del `<script>` en index.html)
- `TELEFONO` → tu WhatsApp con lada, ej. `"524611234567"`.
- `CORREO` → el Gmail donde te llega el aviso.

## Publicarlo para mandarle el link (GitHub Pages)
1. Crea un repositorio en GitHub y sube `index.html`.
2. Settings → Pages → Branch: `main` / root → Save.
3. Te da un link tipo `https://tuusuario.github.io/cita-sorpresa/`. Ese se lo mandas por WhatsApp, Instagram o Gmail.

## Aviso a tu correo
La primera vez que alguien envíe la respuesta, FormSubmit te manda un correo "Activate form". Haz tú una prueba antes, actívalo, y desde ahí cada respuesta te llega sola.
